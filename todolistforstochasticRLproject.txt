Issue 2: Contact sensor가 작동하지 않음
  원인: activate_contact_sensors=False
  해결:
  - ArticulationCfg.spawn.activate_contact_sensors = True 설정
  - ContactSensorCfg 정의 확인

Issue 3: 로봇이 떨어짐 (gravity)
  원인: disable_gravity=False 또는 stiffness 너무 낮음
  해결:
  - disable_gravity=True 설정 (시뮬레이션 환경)
  - Stiffness 값 증가 (arm: 1000-20000, hand: 2-5)

Issue 4: Physics simulation이 불안정함
  원인: solver_iteration_count 너무 낮음
  해결:
  - solver_position_iteration_count: 32
  - solver_velocity_iteration_count: 1

Issue 5: MoveIt2 planning이 자주 실패함
  원인: Collision, IK solution 없음
  해결:
  - Planning time 증가 (5초 → 10초)
  - Grasp pose candidate 더 생성
  - Collision margin 조정

Issue 6: BC pre-training이 converge하지 않음
  원인: Demonstration quality 낮음, learning rate 부적절
  해결:
  - Demonstration filtering (outlier 제거)
  - Learning rate 조정 (3e-4 → 1e-3)
  - Epochs 증가 (50 → 100)

Issue 7: RL training이 학습되지 않음
  원인: Reward scaling, exploration 부족
  해결:
  - Reward weight 조정
  - Entropy coefficient 증가
  - Learning rate 조정

Issue 8: GPU 메모리 부족
  원인: 4096 envs 너무 많음
  해결:
  - num_envs 줄이기 (4096 → 2048)
  - Batch size 줄이기
