질문 2: 물체별 성능 분석이 가능한가요?
================================================================================

답변: 코드 수정 없이는 **제한적으로만** 가능합니다.

현재 상황:
    ✅ 가능: 전체 success rate, sample efficiency, stability 비교
    ❌ 불가능: 물체별 success rate, 물체별 reward 분리

왜 불가능한가:
    - Isaac Lab + RL-Games는 기본적으로 "전체 평균"만 로깅
    - 물체 index 정보가 Tensorboard에 기록 안 됨
    - Environment 내부에만 물체 정보 존재

우리 환경의 물체 (총 16가지):
    1-6:   Cuboids (큐브) - 6가지 크기
    7-8:   Spheres (구) - 2가지 크기
    9-14:  Capsules (캡슐) - 6가지 크기
    15-16: Cones (원뿔) - 2가지 크기

    * Inspire Hand: 0.5x 스케일
    * DG5F Hand:    1.0x 스케일 (Kuka-Allegro baseline과 동일)

코드 수정 없이 가능한 분석:

1. 간접적 분석 (Tensorboard):
    - Success rate variance가 크다 → 물체에 따라 성능 차이 큼
    - Success rate variance가 작다 → 물체 관계없이 일정

2. 질적 분석 (Play 모드 영상):
    python scripts/rsl_rl/play.py \
        --task Isaac-Dexsuite-Ur10e-Inspire-Lift-Play-v0 \
        --num_envs 1 \
        --checkpoint logs/.../model_XXXXX.pt

    → 각 물체별로 성공/실패 육안 관찰
    → "Sphere는 어려워 보이고, Cuboid는 쉬워 보인다" 같은 정성적 파악

논문에 어떻게 쓸 수 있나:

✅ 가능:
    "We observe that both hands achieve consistent performance across
     object geometries (low variance in success rate), suggesting that
     the learning difficulty is dominated by hand actuation structure
     rather than object shape complexity."

❌ 불가능:
    "Inspire Hand achieves 80% on spheres vs 90% on cuboids"
    (정량적 수치 제시 불가)

권장사항:

Main Results:
    → 전체 성능 비교 (Inspire vs DG5F)
    → 이것만으로도 충분히 강력한 contribution!

Discussion/Limitation:
    → 물체별 분석은 안 했다고 명시
    → 질적 관찰은 언급 가능 (영상 있으면)

Future Work:
    "Future work should investigate object-stratified performance
     analysis by logging object indices during training, enabling
     per-object success rate computation and identification of which
     geometries benefit from specific actuation structures."

결론:
    ✅ 전체 성능 비교만으로도 충분히 좋은 논문!
    ✅ 솔직하게 limitation 인정 → 논문 신뢰도 ↑
    ✅ Future work 명확히 제시 → 후속 연구 방향 제시
