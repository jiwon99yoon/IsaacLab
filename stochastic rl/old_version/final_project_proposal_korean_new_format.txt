1.1 배경: 정교한 조작 학습의 샘플 비효율성 문제
-----------------------------------------------

심층 강화학습(RL)은 정교한 조작(dexterous manipulation) 작업에서 놀라운
성공을 거두었으며, 복잡한 손안 물체 재배치에서 인간 수준의 성능을 보여주었
습니다 [1,2]. 그러나 이러한 접근법들은 극심한 샘플 비효율성 문제를 겪으며,
합리적인 성능에 도달하기 위해 종종 수억 번의 환경 상호작용을 필요로 합니다.

**구체적 사례:**
- Rajeswaran et al. [1]: 24-DOF Shadow Hand 학습에 인간 시연 필수
- OpenAI Dactyl [2]: 물체 회전 작업 학습에 약 100년 상당의 시뮬레이션 경험
  필요 (병렬 컴퓨팅으로 실제 48시간 소요)
- DexPBT [6]: Kuka+Allegro (23-DOF) 학습에 집단 기반 훈련 필요

이러한 한계는 데이터 수집이 비용이 많이 들고 시간이 오래 걸리는 실제 로봇
시스템에 RL을 배포하는 것을 심각하게 저해합니다.


1.2 기존 해결책: 모션 플래닝 부트스트랩 RL
-----------------------------------------

최근 연구들은 **모션 플래닝을 사용하여 자동으로 시연을 생성**함으로써 RL을
부트스트랩할 수 있음을 보여주었습니다:

**Abbatematteo et al. [3] (IROS 2021):**
- 운동학 모션 플래닝으로 시연 자동 생성
- 세 가지 작업 (서랍 열기, 전자레인지 닫기, 티볼)에서 검증
- 결과: 모션 플래너 초기화가 무작위 초기화보다 크게 우수, 인간 시연과 경쟁력

**PLANRL [4] (2024):**
- 고전적 플래닝 (웨이포인트 도달) + RL (정밀 조작) 동적 전환
- UR3e + Robotiq Hand-e 그리퍼 사용
- 결과: 실제 로봇에서 simple tasks 90%, complex tasks 75% 성공률

**SILP+ [5] (2023):**
- 성공적인 RL 상태로부터 자기 모방 학습
- UR5e 팔 사용
- 결과: 시뮬레이션 90%, 실제 로봇 90% 성공률


1.3 핵심 연구 격차: 고자유도 정교한 손에 대한 미적용
---------------------------------------------------

**선행 연구의 공통 한계:**
모든 모션 플래닝 부트스트랩 RL 접근법들 [3,4,5]은 **단순한 평행 집게를 가진
로봇 팔 (6-7 자유도)**에만 제한되었습니다. 접촉이 많은 조작 작업을 위한
**고자유도 정교한 손 (20+ 자유도)**에 이 방법론을 적용한 선행 연구는
존재하지 않습니다.

**격차의 원인:**
모션 플래닝 부트스트랩 RL을 정교한 손으로 확장하는 것은 세 가지 핵심
도전에서 비롯됩니다:

1) **고차원 행동 공간**
   - 선행 연구: 6-7 DOF
   - 정교한 손: 20+ DOF (3-4배 증가)
   - 도전: 차원의 저주, 탐색 공간 폭발

2) **접촉이 풍부한 동역학**
   - 선행 연구: 자유 공간 도달 또는 단순 집게
   - 정교한 손: 다중 손가락 파지, 접촉력 제어 필수
   - 도전: 운동학 플래너가 접촉 동역학을 포착할 수 없음

3) **다중 손가락 협응**
   - 선행 연구: 단일 집게 개폐
   - 정교한 손: 5개 손가락 독립/협조 제어
   - 도전: 운동학 플래닝만으로는 안정적 파지 불가능

- 특징: 기계적 결합(underactuation), compliance 기반 파지

**2.2.2 Phase 1: 자동 시연 생성 (Automated Demonstration Generation)**

**목표:** 인간 입력 없이 운동학적으로 타당한 시연 자동 생성

**방법론 [3 확장]:**

Step 1. 목표 샘플링
```
Input: 물체 초기 자세 (x₀, y₀, z₀)
Output: 목표 자세 (xₜ, yₜ, zₜ)

xₜ ~ Uniform(x₀ - 0.1, x₀ + 0.1)  # 물체 주변 ±10cm
yₜ ~ Uniform(y₀ - 0.1, y₀ + 0.1)
zₜ ~ Uniform(z₀ + 0.1, z₀ + 0.3)  # 위로 들어올림
```

Step 2. Motion Planning (MoveIt2)
```
Planner: RRT-Connect
Planning group: arm + hand (전체 26-DOF/12-DOF)
Constraints:
  - Collision-free path
  - Joint limits
  - Velocity/acceleration limits
Output: Joint trajectory τ = {q₀, q₁, ..., qₜ}
```

Step 3. 궤적 실행 및 기록
```
For each timestep t:
  1. 현재 state 관측: sₜ = (joint_pos, joint_vel, object_pose, ...)
  2. Action 실행: aₜ = qₜ (joint position command)
  3. 다음 state 관측: sₜ₊₁
  4. 저장: (sₜ, aₜ, sₜ₊₁)
```

**Fallback Plan (위험 완화):**
MoveIt2 통합이 복잡할 경우:
- Option A: Isaac Sim 내장 RMPflow planner 사용
- Option B: Cubic spline으로 부드러운 synthetic trajectories 생성


**2.2.3 Phase 2: Behavior Cloning (BC) Pre-training**

**목표:** Demonstration으로부터 정책 초기화

**Network Architecture:**
```
Input: Observation (64-dim)
  - Robot state: joint pos/vel (26-dim or 12-dim)
  - Object state: pose, velocity (13-dim)
  - Goal state: target pose (7-dim)
  - Fingertip states: positions, contact (18-dim)

Hidden Layers:
  - FC(256) → ReLU → LayerNorm
  - FC(256) → ReLU → LayerNorm
  - FC(128) → ReLU → LayerNorm

Output: Action (26-dim or 12-dim)
  - Joint position commands
  - Tanh activation (normalized [-1, 1])
```

**Training:**
```
Loss: Mean Squared Error (MSE)
  L_BC = 1/N Σᵢ ||π_θ(sᵢ) - aᵢ||²

Optimizer: Adam (lr=3e-4)
Batch size: 256
Epochs: 50
Early stopping: patience=10 (validation loss)
Train/Val split: 90/10
```

**검증 기준:**
- Validation loss < 0.01
- 실제 환경 테스트 success rate > 30%


**2.2.4 Phase 3: Contact-Aware Reward Shaping (핵심 기여)**

**동기:**
기존 RL 정교한 조작 연구들 [1,2,6]은 "지름길 행동(shortcut behavior)" 문제를
보고했습니다:
- 손가락 대신 팔로 물체 밀기
- 순간적 두드림으로 물체 튕기기
- 바닥 반발력을 악용한 들어올리기

**해결책: 접촉 인지 보상 형성**

본 연구는 3가지 접촉 특화 보상 항을 도입합니다:


**Reward Term 1: Contact Gating (접촉 게이팅)**
```
목적: 손가락-물체 접촉이 있을 때만 위치 추적 보상 활성화

수식:
  R_gated = R_position × I(contact_force > τ)

where:
  R_position = -||p_object - p_goal||  (위치 추적)
  I(·): Indicator function
  τ = 0.1 N (접촉 임계값)

효과: 팔 밀기 지름길 방지
```


**Reward Term 2: Grasp Duration (파지 지속 시간)**
```
목적: 지속적인 다중 손가락 접촉 장려

수식:
  R_duration = (1/N_fingers) × Σⱼ I(contact_jₜ₋ₘ:ₜ > τ)

where:
  contact_jₜ₋ₘ:ₜ: 손가락 j의 최근 m timesteps 접촉 이력
  m = 10 steps (최소 지속 시간)

효과: 순간적 두드림 방지, 안정적 파지 장려
```


**Reward Term 3: Ground Contact Penalty (지면 접촉 벌점)**
```
목적: 물체-바닥 충돌 벌점

수식:
  R_ground = -w × I(F_object_z > τ_ground)

where:
  F_object_z: 물체의 상향 힘 (바닥 반발력)
  τ_ground = 1.0 N
  w = 0.5 (벌점 가중치)

효과: 바닥 튕김 악용 방지
```


**Total Reward:**
```
R_total = w₁·R_gated + w₂·R_duration + w₃·R_ground + R_baseline

where:
  R_baseline: 기존 rewards (lifting, orientation, etc.)
  w₁ = 2.0, w₂ = 1.0, w₃ = 0.5 (튜닝된 가중치)
```


**핵심 통찰 (Key Insight):**
```
┌─────────────────────────────────────────────────────────────┐
│ Motion Planning: 운동학적 실행 가능성 (kinematic feasibility)│
│           +                                                  │
│ Contact-Aware Rewards: 동역학적 안정성 (dynamic stability)  │
│           =                                                  │
│ Robust Dexterous Grasping                                   │
└─────────────────────────────────────────────────────────────┘

모션 플래닝만으로는 안정적 파지를 보장할 수 없습니다.
접촉 인지 보상이 RL을 안내하여 플래너가 포착하지 못한
접촉 동역학을 학습하도록 합니다.
```


**2.2.5 실험 설계: Ablation Study**

**목적:** 각 구성 요소의 기여도 정량화

**4가지 변형 (Variants):**

| Variant | BC Init | Contact Rewards | 비고              |
|---------|---------|-----------------|-------------------|
| V1      | ✗       | ✗               | Pure PPO (baseline)|
| V2      | ✓       | ✗               | Motion planning 효과|
| V3      | ✗       | ✓               | Contact rewards 효과|
| V4      | ✓       | ✓               | Full method       |

각 variant를 2개 로봇에서 실행: 총 8개 실험

**Training Setup:**
- Algorithm: PPO (RL-Games)
- Parallel envs: 4096
- Training epochs: 5000
- Episode length: 500 steps
- Batch size: 16384 (4096 envs × 4 steps)
- Learning rate: 3e-4
- Discount factor (γ): 0.99

**평가 메트릭:**
1. Success rate: 목표 도달 에피소드 비율
2. Sample efficiency: 80% 성공률 도달까지 필요한 샘플 수
3. Contact force statistics: 평균/최대 접촉력
4. Grasp quality: 접촉점 개수, 힘 폐쇄(force closure)

**Contribution T1: 고자유도 시스템에 대한 모션 플래닝 부트스트랩 확장**

기존 이론 [3]은 저자유도 로봇 팔(7-DOF)에서 모션 플래닝 부트스트랩의

```

     증가해도 유지된다.

근거:
  1. Kinematic feasibility는 차원과 무관
  2. BC pre-training은 policy gradient의 초기 탐색 공간을 제약
  3. 고차원일수록 무작위 초기화 대비 이득이 더 클 수 있음
```


**Contribution T2: 접촉 동역학과 모션 플래닝의 상보성**

본 연구는 운동학 플래닝과 접촉 기반 보상 형성의 상보적 관계를 규명합니다:

```
이론적 프레임워크:
┌────────────────────────────────────────────────────┐
│ Motion Planning: Kinematic Initialization          │
│   → 실행 가능한 궤적 공간으로 정책 제약              │
│   → 충돌 회피, 관절 한계 준수                       │
│   → But: 접촉 동역학 무시                           │
├────────────────────────────────────────────────────┤
│ Contact-Aware Rewards: Dynamic Refinement          │
│   → RL이 안정적 파지 전략 학습                      │
│   → 다중 손가락 협응 최적화                          │
│   → 접촉력 제어 학습                                 │
└────────────────────────────────────────────────────┘

결합 효과: 각각의 한계를 상호 보완
```

이는 접촉이 많은 조작 작업에서 모션 플래닝과 RL의 통합 방법론에 대한
이론적 근거를 제공합니다.


**Contribution T3: Under-actuated vs Fully-actuated Hands의 학습 특성**

본 연구는 두 가지 구동 메커니즘의 학습 특성을 비교 분석합니다:

```
가설:
  H_underactuated: 저구동 손은 기계적 결합으로 인해 운동학 플래닝
                   부트스트랩의 이득이 제한적

  H_fullyactuated: 완전구동 손은 모든 관절 독립 제어 가능하므로
                   운동학 플래닝이 더 효과적

경험적 검증을 통해 이론적 이해 향상
```


3.2 알고리즘적 기여 (Algorithmic Contributions)
----------------------------------------------

**Contribution A1: Automated Demonstration Generation Pipeline**

인간 개입 없이 자동으로 고품질 시연을 생성하는 파이프라인:

```
Algorithm: Auto-Demo Generation
──────────────────────────────────────────────────
Input: Robot URDF, Task specification
Output: N demonstrations {(s,a)}ⁿᵢ₌₁

1. For i = 1 to N:
2.   Sample goal pose g ~ p(G)
3.   Plan trajectory τ ← MoveIt2.plan(q_current, g)
4.   If τ is valid:
5.     Execute τ in Isaac Sim
6.     Record (state, action) pairs
7.     Validate trajectory (collision-free, smooth)
8.     If valid: Save demonstration
9. Convert to Isaac Lab format
10. Return demonstrations
──────────────────────────────────────────────────
```

**혁신점:**
- 기존: 인간 원격 조작 ($10,000+ 하드웨어 필요)
- 본 연구: 완전 자동화 (0 인간 시간)
- 확장성: GPU 병렬화로 대량 생성 가능


**Contribution A2: Contact-Aware Reward Shaping Framework**

정교한 조작을 위한 체계적인 reward shaping 프레임워크:

```
Framework: Contact-Aware Reward Design
──────────────────────────────────────────────────
Components:
  1. Contact Gating: Task rewards × Contact indicator
  2. Grasp Duration: Sustained multi-finger contact
  3. Ground Penalty: Object-table collision penalty

Design Principles:
  - Reward sparsity 해결: Contact gating으로 dense signal
  - Shortcut prevention: Duration + Penalty terms
  - Multi-finger coordination: Good finger contact term
  - Interpretability: 각 term의 명확한 목적

Hyperparameters (tuned):
  - Weights: w₁=2.0, w₂=1.0, w₃=0.5
  - Thresholds: τ_contact=0.1N, τ_ground=1.0N
  - Duration: m=10 steps
──────────────────────────────────────────────────
```


**Contribution A3: DQfD-style Demonstration Integration**

BC pre-training과 RL의 효과적인 결합 방법:

```
Algorithm: BC-Bootstrapped PPO
──────────────────────────────────────────────────
Phase 1: BC Pre-training
  - Supervised learning on demonstrations
  - 50 epochs, validation-based early stopping

Phase 2: RL Fine-tuning
  - Initialize policy with BC weights
  - Maintain demonstration buffer (25% sampling ratio)
  - Prioritized replay: demo > self-generated data
  - Auxiliary BC loss during RL:
      L_total = L_PPO + λ·L_BC
      where λ decays over training

Benefits:
  - Stable initialization
  - Prevents catastrophic forgetting
  - Maintains expert behavior while exploring
──────────────────────────────────────────────────
```


3.3 실용적 기여 (Practical Contributions)
-----------------------------------------

**Contribution P1: 샘플 효율성 향상**

**예상 결과:**
```
Pure PPO (baseline):
  - 80% 성공률까지: ~100M samples (5000 epochs × 4096 envs × 500 steps)
  - 훈련 시간: ~24시간

BC + PPO + Contact (full method):
  - 80% 성공률까지: ~25-50M samples (2-4× faster)
  - 훈련 시간: ~6-12시간

실질적 이득:
  - 훈련 시간 절감: 12-18시간 (50-75% 감소)
  - 전력 소비 절감: ~50-75% (GPU 사용 시간 비례)
  - 실제 로봇 적용 시: 데이터 수집 시간/비용 대폭 절감
```
