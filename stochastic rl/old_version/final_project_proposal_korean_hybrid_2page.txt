1. MOTIVATION
================================================================================

심층 강화학습(RL)은 정교한 조작 작업에서 인간 수준의 성능을 보여주었으나
[1,2], 극심한 샘플 비효율성 문제를 겪습니다. 예를 들어, OpenAI Dactyl [2]은
큐브 회전 학습에 100년 상당의 시뮬레이션이 필요했습니다. 이는 실제 로봇
시스템 배포를 심각하게 저해합니다.


1.1 기존 해결책과 연구 격차
-------------------------

최근 연구들은 모션 플래닝으로 자동 시연을 생성하여 RL을 부트스트랩하는
방법을 제안했습니다 [3,4,5]. Abbatematteo et al. [3]은 운동학 플래닝 기반
시연이 무작위 초기화보다 우수함을 보였고, PLANRL [4]은 실제 로봇에서 90%
성공률을 달성했습니다. 그러나 이들은 모두 단순 집게를 가진 로봇 팔(6-7 DOF)
에만 제한되었습니다.

고자유도 정교한 손(20+ DOF)으로의 확장은 세 가지 도전을 수반합니다: (1) 행동
공간이 3-4배 증가하여 탐색이 어려움, (2) 운동학 플래너가 접촉 동역학을 포착
불가, (3) 다중 손가락 협응이 필요하나 운동학만으로 안정적 파지 불가능.
따라서 본 연구는 모션 플래닝 부트스트랩 RL을 고자유도 손으로 확장하고,
접촉 인지 보상을 통해 샘플 효율성을 개선하고자 합니다.


================================================================================
2. PROBLEM DESCRIPTION
================================================================================

본 연구는 UR10e 로봇 팔(6-DOF)에 두 가지 정교한 손을 결합한 시스템을
사용합니다: UR10e-DG5F (26-DOF, 완전구동 5지 그리퍼)와 UR10e-Inspire
(12-DOF, 저구동 5지 그리퍼). 다양한 물체 들기 작업을 학습하며, Isaac Lab
환경에서 GPU 가속(4096 병렬 환경)으로 RL-Games PPO를 훈련합니다.


2.1 3단계 프레임워크
------------------

**Phase 1: 자동 시연 생성 (Isaac Sim + MoveIt2)**
MoveIt2 모션 플래너를 사용하여 목표 자세에 대한 충돌 없는 궤적을 계획하고,
Isaac Sim에서 실행하여 (state, action) pairs를 기록합니다. 로봇당 1000개
시연을 생성하여 Isaac Lab 형식으로 변환합니다.

**Phase 2: Behavior Cloning 사전 훈련**
3층 FC network (256-256-128 units)를 사용하여 시연 데이터로 정책을 사전
훈련합니다. MSE 손실로 50 epochs 훈련하며, >30% 성공률을 목표로 합니다.

**Phase 3: RL 미세 조정 + 접촉 인지 보상**
BC policy로 초기화 후, 접촉 특화 보상과 함께 PPO 훈련을 수행합니다(5000
epochs). Demonstration buffer를 유지하여 25% demo + 75% RL data로 학습합니다.


2.2 핵심 기여: 접촉 인지 보상 형성
---------------------------------

정교한 조작 RL의 지름길 행동(팔 밀기, 바닥 튕김 악용 등) 문제를 해결하기
위해 세 가지 접촉 특화 보상을 도입합니다:

(1) **접촉 게이팅:** 손가락-물체 접촉 시에만 위치 추적 보상 활성화
    R_gated = R_position × I(F_contact > 0.1N)

(2) **파지 지속 시간:** 다중 손가락의 지속적 접촉 장려 (최소 10 steps)
    R_duration = (1/N_fingers) × Σⱼ I(sustained_contact_j)

(3) **지면 벌점:** 물체-바닥 충돌에 벌점
    R_ground = -0.5 × I(F_object_z > 1.0N)

총 보상: R_total = 2.0·R_gated + 1.0·R_duration + R_ground + R_baseline

**핵심 통찰:** 모션 플래닝은 운동학적 실행 가능성을, 접촉 보상은 동역학적
안정성을 제공하여 상호 보완적으로 견고한 파지를 가능하게 합니다.


2.3 실험 설계
------------

4가지 변형의 ablation study를 수행합니다: (1) Pure PPO (baseline), (2) BC +
PPO, (3) PPO + Contact, (4) BC + PPO + Contact (full method). 각 변형을 2개
로봇에서 실행하여 총 8개 실험을 수행하며, 성공률, 샘플 효율성(80% 성공까지
필요 샘플), 접촉력 통계, 파지 품질을 평가합니다. 우리는 full method가 pure
PPO 대비 2-4배 빠른 수렴과 80%+ 성공률을 달성할 것으로 예상합니다.

3. EXPECTED CONTRIBUTION
================================================================================

3.1 이론적/알고리즘적 기여
-------------------------

**(1) 고자유도 시스템으로의 확장:** 모션 플래닝 부트스트랩 RL [3]을 7-DOF
로봇 팔에서 26-DOF 정교한 손으로 확장하여, 샘플 효율성 이득이 고차원에서도
유지됨을 검증합니다.

**(2) 운동학-동역학 상보성:** 운동학 플래닝(충돌 회피, 실행 가능성)과 접촉
보상(안정적 파지, 손가락 협응)의 결합이 각각의 한계를 상호 보완함을 규명합니다.

**(3) 자동 시연 생성 파이프라인:** 인간 원격 조작($10,000+ 하드웨어) 없이
완전 자동화된 시연 생성 방법을 제시합니다.

**(4) 접촉 인지 보상 프레임워크:** 정교한 조작을 위한 체계적 reward shaping
(contact gating, duration, penalty)을 제공합니다.


3.2 실용적 기여 및 영향
----------------------

**(1) 샘플 효율성 향상:** Pure PPO는 80% 성공률까지 약 100M 샘플과 24시간이
필요하지만, full method는 25-50M 샘플과 6-12시간으로 달성하여 2-4배 빠른
수렴과 50-75% 훈련 시간 절감을 제공합니다.

**(2) 비용 절감:** 인간 시연 수집($10,000+ 하드웨어, 8-83시간 인간 시간)
또는 순수 RL(100년 시뮬레이션, $3,500+ 전력) 대비, 자동 시연 생성(하드웨어
$0, 설정 1시간, 자동 생성 4-8시간)으로 대폭 절감합니다.

**(3) 실제 배포 가능성 검증:** UR10e 기반 시스템에서 학습한 정책을 실제
로봇으로 전이하여, 새로운 물체에 대해 몇 시간 만에 자동 시연 생성 및 빠른
훈련으로 신속 적응이 가능함을 검증합니다.

**(4) 오픈소스 기여:** Isaac Lab 커뮤니티를 위한 demonstration toolkit,
contact-aware reward library, 구현 가이드를 제공하여 재현성과 실제 적용을
가속화합니다.


장기적으로, 본 연구는 고자유도 로봇 학습의 샘플 효율성 향상 방법론 제시,
모션 플래닝과 RL 통합의 이론적 이해 증진, 접촉 조작 작업의 reward shaping
가이드라인 제공 등의 과학적 영향과 함께, 정교한 조작 RL의 실용성 향상,
로봇 RL 적용 확대, 중소기업의 RL 기술 접근성 향상 등의 기술적/경제적
영향을 가질 것입니다.
